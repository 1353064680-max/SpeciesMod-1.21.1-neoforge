> 一个为 Minecraft 1.21.1 (NeoForge) 打造的种族选择模组。选择属于你的种族，获得独特的被动增益、减益以及专属主动技能！

---

## 📖 简介

SpeciesMod 为游戏添加了 **11 个独特种族**，每个种族都拥有精心设计的属性修饰符、被动效果和主动技能。种族的选择将深刻影响你的游戏风格——从近战战斗到水下探索，从空中飞行到远程射击，总有一个种族适合你。

## 🎮 操作方式

| 按键 | 功能 |
|------|------|
| `\` (反斜杠) | 切换种族能力（启用/禁用被动效果） |
| `G` | 激活种族主动技能 |

## 🛠️ 管理员命令

需要权限等级 4（OP）：

```
/species list                              # 列出所有在线玩家及其种族
/species player <玩家>                     # 查看指定玩家的种族
/species reset <玩家>                      # 重置指定玩家的种族选择
/species set <玩家> <种族ID>               # 设置指定玩家的种族
```

**可用种族ID：** `human` `catkin` `dogkin` `foxkin` `wingedbeast` `aquatic` `slimekin` `elf` `plantkin` `cursed` `aigoth`

## 📁 项目结构

```
src/main/java/com/aigoth/species/
├── SpeciesMod.java          # 模组主类
├── Config.java              # 配置
├── capability/              # 种族数据能力系统
├── race/                    # 种族定义（每个种族一个类）
├── event/                   # 种族事件处理器
├── item/                    # 物品注册与实现
├── network/                 # 网络包（技能、二段跳等）
├── screen/                  # 种族选择界面
├── command/                 # 管理员命令
├── input/                   # 按键绑定
├── effect/                  # 效果管理
├── data/                    # 数据持久化
└── client/                  # 客户端工具
```
